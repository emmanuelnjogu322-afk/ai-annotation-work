# AI Annotation Work

Practical AI data annotation portfolio focused on visual reasoning, consistency, and quality control.

## Day One

Day One documents foundational image/video annotation reasoning:
- identifying object classes
- separating object instances
- handling partial visibility
- distinguishing visible evidence from assumptions
- recording uncertainty before making an annotation decision
- validating annotation consistency

## Portfolio principle

The objective is not simply to produce labels. It is to make the reasoning behind annotation decisions inspectable, repeatable, and improvable.
